# ttelegram — передача в ttools

Версия: **2026.11.18.4**. Первая платформа: **Linux x86_64, glibc ≥2.28, CPython 3.14**. SteamOS проверена. Другие версии Python, архитектуры, Windows и macOS этой поставкой не поддерживаются. Это локально доработанный клиент, а не голый tg из PyPI.

## Установка и команды

`${HOME}`, `${PREFIX}`, `${BUNDLE}` — подстановки общего клиента ttools, не синтаксис shell. `${BUNDLE}` — абсолютный каталог этой поставки; `${PREFIX}` — отдельный пользовательский каталог установки. В app.json записан точный argv каждого действия. Не добавлять shell=True.

- Install-only: `["python3", "${BUNDLE}/install.py", "--prefix", "${PREFIX}"]`
- Запуск: `["${PREFIX}/bin/ttelegram"]`
- Версия: `["python3", "${PREFIX}/manage.py", "--prefix", "${PREFIX}", "--version"]`
- Штатный выход: `["python3", "${PREFIX}/manage.py", "--prefix", "${PREFIX}", "--stop-only"]`
- Обновление: `["python3", "${PREFIX}/manage.py", "--prefix", "${PREFIX}", "--manifest", "${BUNDLE}/update.json", "--stop"]`
- Откат: `["python3", "${PREFIX}/manage.py", "--prefix", "${PREFIX}", "--rollback", "--stop"]`
- Проверка системных зависимостей: `["python3", "${BUNDLE}/install.py", "--prefix", "${PREFIX}", "--check"]`

Установка не открывает интерфейс и не запрашивает Telegram-авторизацию. Python-зависимости устанавливаются **без сети** из wheels/. Пользовательский venv не копируется: новый создаётся установщиком. Обычный запуск ничего не устанавливает. Системные пакеты предварительно ставит ttools/пользователь средствами ОС; установщик не вызывает sudo и не меняет SteamOS read-only root. При нехватке зависимости он завершается до переключения версии.

## Зависимости и лицензии

Обязательные для полного набора функций: CPython3.14 с venv/ensurepip/curses; tmux≥3.4; ffmpeg/ffprobe с libopus и PulseAudio; ffplay; kdialog; системный `/usr/bin/python3` с PyGObject/GTK3. Для записи нужен рабочий PulseAudio/PipeWire Pulse и микрофон. Для обычных картинок нужен терминал SIXEL; проверен Konsole с tmux3.7b. DOTS доступен отдельно в настройках.

Дополнительно: wl-paste для Wayland-буфера (при отсутствии используется GTK/Xwayland); less/xdg-open/редактор для внешних файлов; xclip/wl-copy для старых обработчиков копирования tg. Они не требуются для установки и базового запуска.

requirements.txt закрепляет tg0.26.0, python-telegram2.0.0, Pillow13.0.0, qrcode8.2, rlottie-python1.3.8, standard-mailcap3.13.0, telegram-text0.2.0. Linux-wheel python-telegram содержит **TDLib1.8.66**, загрузка и запрос версии проверены без авторизации. Отдельно системная TDLib не требуется; подмена через PYTHON_TELEGRAM_TDLIB_PATH остаётся пользовательским непроверенным вариантом.

Локальное изменение upstream: `vendor/tg-0.26.0-views.patch` и соответствующий `vendor/views.py`. Установщик сверяет SHA-256 исходного tg/views.py перед заменой; на другой версии не применяет патч. `vendor/patch.json` содержит оба хеша. tg — **Unlicense**, текст в `vendor/TG-LICENSE.txt`, получен из официального upstream UNLICENSE. Лицензии остальных зависимостей находятся в их исходных wheel. Публичный репозиторий именно ttelegram не подтверждён; эта поставка не объявляет репозиторий tg репозиторием приложения.

## Обновление и откат

Владелец обновлений — **ttools**. Рабочий минимальный механизм реализован в install.py/manage.py: читает локальный JSON или HTTPS-манифест, проверяет app_id/платформу/версию и SHA-256 артефакта, безопасно распаковывает, проверяет внутренние SHA256SUMS, создаёт отдельный releases/VERSION и атомарно переключает current. previous сохраняет прошлую версию. Установочная блокировка flock исключает параллельную установку/обновление/откат.

**Публичного HTTPS-манифеста и публичного релиза сейчас нет.** Поэтому update_manifest_url и artifact.url равны null; update.json содержит существующий локальный артефакт и реальный SHA-256. Обновление из этого артефакта реально проверено между двумя версиями. После публикации ttools может заменить null реальными HTTPS URL и передать URL через --manifest; HTTPS-ветка реализована, но не проверялась против опубликованного сервиса. Фонового планировщика нет. F8 сообщает, что обновления устанавливает ttools; простой перезапуск больше не называется обновлением. SHA-256 обеспечивает целостность относительно доверенного манифеста, не заменяет подпись издателя.

Если клиент запущен, установка без --stop отказывается менять версию. С --stop завершается собственный worker через SIGTERM с сохранением состояния; установщик ждёт завершения своей tmux-сессии до 10 секунд и при зависании отменяет операцию. Чужие сессии tmux не трогаются. Имя socket привязано к PREFIX; launcher передаёт его runtime. Ошибка установки до активации оставляет current прежним. Откат переключает на previous, пользовательские данные не откатываются.

## Данные и allowlist

source/ALLOWLIST.json перечисляет кодовые файлы; source/MANIFEST.json содержит хеши. В поставке нет пользовательского venv, conf.py, номеров телефона, ключей аккаунта, TDLib-баз, переписки, журналов, voice/ и cache/. Wheels загружены заново как зависимости, а не извлечены из пользовательского окружения.

Данные сохраняются вне PREFIX: ~/.config/ttelegram (настройки, черновики, последний чат), ~/.config/tg (пользовательская конфигурация), ~/.cache/tg (авторизация/база TDLib), ~/.cache/ttelegram (превью, буфер, голосовые), ~/.local/share/tg (журналы upstream). Не удалять эти пути при обновлении/переустановке. Старый ~/.local/share/ttelegram/voice может существовать у прежней локальной установки; он не упакован и не удаляется.

Оригинальный локальный клиент в ~/.local/share/ttelegram не заменён тестовым PREFIX. Перед переключением общего ttools на новую установку необходимо штатно завершить старый клиент: TDLib-база одного аккаунта не допускает два одновременных процесса.

## Проверено и ограничения

Подробности: test-results.json. Проверены офлайн install-only, повторная установка, версия, загрузка TDLib, обновление 2026.11.18.1→2026.11.18.4, откат и отказ неправильному хешу без смены current. Установка и fake-runtime проверены в `/tmp/Тест ttelegram/пользователь`: tmux-конфигурация, справка, настройки, сохранение черновика и Ctrl+Q. Тестовая ошибка из-за общих файлов двух fixtures устранена изоляцией файлов состояния; повторная проверка прошла.

На отдельном окне Konsole проверены клики/стрелки без изменения геометрии, возврат списка чатов, справка, настройки. Запись голосового проверена синтетическим тоном: остановка не отправляет; отмена удаляет запись; отдельное подтверждение вызывает fake backend, Opus/waveform корректны. Реальные сообщения и запись микрофона для тестов не использовались.

Для повторения без входа: установить пакет, затем запустить `${PREFIX}/current/venv/bin/python ${BUNDLE}/tests/fake_client.py` в отдельной tmux-сессии с TTELEGRAM_TEST_RUNTIME=${PREFIX}/current. Fixture использует только искусственные чаты и генерирует однотонное тестовое изображение. Это smoke fixture; вход в реальный аккаунт она не выполняет. Нужен терминал, TERM=tmux-256color и allow-passthrough on для проверки SIXEL.

Не проверено: чистая другая Linux-машина без уже установленных системных зависимостей, физический микрофон, опубликованный HTTPS-канал, другие терминалы и платформы. QR/2FA и авторизация сохранены в коде; пакетные тесты не входили в настоящий аккаунт.

## Изменения 2026.11.18.4

Текущий вывод картинок использует нативное хранение SIXEL внутри tmux, без passthrough для каждого изображения и без таймеров refresh-client. Нужен tmux, собранный с SIXEL (проверен 3.7b). Старое описание полной перерисовки относится к версии .3 и заменено этим механизмом. Голосовая запись находится внутри composer: Ctrl+G начало/стоп, P воспроизведение/стоп повторяемо, Enter отправка, Esc удалить. Волна рассчитывается только из PCM выбранного microphone-source; monitor-source не выбирается. Нужен pactl.

Проверка пикселей в Konsole: после выхода из записи и четырёх принудительных refresh-client количество красных и зелёных пикселей тестового изображения оставалось одинаковым (207004 и 147696). Настройки полностью очищают изображение, возврат восстанавливает его. Проверка голоса использовала синтетический источник (тишина, затем тон), SDL dummy playback и fake Telegram backend. Настоящий микрофон и настоящие отправки для этих тестов не использовались.
