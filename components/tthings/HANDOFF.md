# tthings 0.7.0

Пакет для ttools. Версия исходников, runtime и каталога согласована. Дата и SHA-256 — update.json и SHA256SUMS.txt. Публичного релиза/HTTPS-канала нет: URL=null, артефакты реально находятся в runtime/. Обновляет ttools, приложение самостоятельно файлы не меняет.

## Точный argv

Пути ${BUNDLE}, ${PREFIX}, ${HOME} подставляет клиент, без shell. ${PREFIX} — отдельный пользовательский каталог, например ${HOME}/.local/share/ttools/apps/tthings. Python3 >=3.10 нужен установщику; Linux runtime после установки автономен.

Установка: ["python3", "${BUNDLE}/install.py", "install", "--prefix", "${PREFIX}"]
Обновление: ["python3", "${BUNDLE}/install.py", "apply", "--prefix", "${PREFIX}"]
Запуск Linux runtime: ["${PREFIX}/bin/tthings"]
Версия: ["${PREFIX}/bin/tthings", "--version"]
Завершение: ["python3", "${BUNDLE}/install.py", "stop", "--prefix", "${PREFIX}"]
Откат: ["python3", "${BUNDLE}/install.py", "rollback", "--prefix", "${PREFIX}"]

Исходный fallback: добавить --source-fallback при установке; запуск/версия через ["python3", "${PREFIX}/bin/tthings", ...]. Установка не запускает интерфейс, не регистрирует глобальные клавиши, не требует sudo/аккаунта/сети. Обычная пользовательская --install тоже больше не регистрирует клавиши без --with-hotkeys. Старые пользовательские shortcuts не удаляются.

SHA проверяется до замены. Каталог и версия проверяются до и после активации; ошибка активации восстанавливает предыдущий файл и метаданные. flock исключает одновременную установку/обновление и изменение файлов при управляемом процессе. Повторная установка того же SHA ничего не меняет. stop посылает SIGINT только зарегистрированным процессам данного prefix с проверкой PID/start-time, ждёт завершения. Старые неуправляемые процессы ttools завершает через собственный Popen до первой миграции. Настройки и журналы не перезаписываются, пользовательские данные в пакет не включены.

## Возможности и платформы

200 встроенных эффектов (70 новых в 0.7.0), 11 системных инструментов, 41 ссылка на внешние проекты: внешние проекты НЕ устанавливаются. --version, --list --json, --effect, --tool, --snapshot, --duration, --window, --region сохранены. Заголовок OSC0: tthings — название эффекта/инструмента. Встроенный терминал лаунчера должен обрабатывать OSC0 для названия вкладки.

Системная информация собирается без запуска fastfetch. Каталог 541 логотипа встроен с MIT-уведомлением Fastfetch. Определение ОС нативное, неизвестный Linux получает Linux, а не SteamOS.

Реально собран и проверен Linux x86_64 / SteamOS glibc2.43. Максимальное требование символов bundled ELF: GLIBC_2.42; на 2.42 отдельно НЕ запускался. Для старой glibc — Python zipapp. Windows/macOS исходники предусмотрены, но нативных сборок и реальной проверки нет. Для мониторинга на них требуется psutil (включать в будущие бинарники), для часовых поясов при отсутствии системной базы tzdata. Linux терминальный режим работает без них. Tk нужен отдельным обычным окнам; Linux выделение требует Qt6/QML и KWin. Глобальные клавиши/магнитное выделение на живом рабочем столе в этой среде не проверены. Другим ОС Linux-бинарник не выдавать.

## API фона

source/tthings/renderer.py, API_VERSION=1, MIT. Импортировать весь пакет tthings, не копировать только effects.py/extra_effects.py: нужны также rich_effects.py, light_effects.py и generative_effects.py и gallery_effects.py.

```python
from tthings.renderer import create_renderer
renderer = create_renderer('light_ribbons', 100, 30, brightness=.18, max_fps=12)
frame = renderer.next_frame()  # None не возвращает, повторный вызов может дать кеш
renderer.resize(120, 40)
frame = renderer.render(3.5)  # elapsed seconds
# frame.cells[y][x] = (Unicode character, '#rrggbb')
```

Нет окна, потоков, управления терминалом; цикл и вывод принадлежат ttools. Яркость 0..1, ограничение до300x140, next_frame ограничивает частоту. Данные ОС не выдумываются, история графиков копится по реальным замерам.

Реальный desktop недоступен: проверены терминальные кадры и PNG-превью, не взаимодействие с окнами рабочего стола.
