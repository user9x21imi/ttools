# Third-party components

The package includes an offline catalog of 541 ASCII logos exported from the
Fastfetch 2.70.0 built-in logo library. Source:
https://github.com/fastfetch-cli/fastfetch/tree/2.70.0
License: MIT (licenses/fastfetch-LICENSE).
No Fastfetch executable is shipped or needed at runtime.
Platform facts are collected using native system APIs and bundled Python modules.
The generic 3D renderer and typography are original tthings code.
Python/Tcl/Tk/PyInstaller and optional psutil/tzdata retain their runtime licenses.
Other external catalog entries are not bundled and are unrelated to the system view.
