# Проверка 2026-11-17

Проверено локально на SteamOS x86_64, Python 3.14:

- 9 unittest-проверок: все 19 эффектов при 6 размерах от 1×1 до 130×40,
  несколько моментов анимации и повторное уменьшение; алгоритм «Жизни»;
  рост бонсая; позиции точек Брайля; каталог и Unicode-поиск;
  поиск переносимых инструментов; запись/восстановление настроек;
  JSON CLI и сообщение об отсутствии терминала.
- Интерактивный запуск в PTY 110×30: поиск «лава», Enter, запуск,
  палитра, пауза/продолжение, resize 38×12, выход в меню,
  переключение встроенных/оригиналов, штатный выход с восстановлением терминала.
- Установка одной командой с временным HOME; запуск установленного
  автономного zipapp из `/tmp`, отдельно от исходников.
- Отсутствие графического display даёт понятную ошибку.

Отдельно собирается и проверяется локальный Linux-бинарник PyInstaller.

Не проверено: живой Tk-интерфейс, мышиное выделение, позиционирование,
глобальные клавиши, другие мониторы/DPI, фактический запуск на macOS/Windows,
совместимость Linux-бинарника со старыми glibc. Доступ к X11 и D-Bus
из sandbox запрещён; попытки прямого подключения вернули отказ.
Внешние 34 проекта не устанавливались и их фактический запуск не проверялся.

## Исправление 0.1.1: прозрачное выделение

- На SteamOS/Linux удалён полноэкранный тёмный выделитель Tk.
- Новый Qt 6 QML слой не рисует фон и заливку выделения; только контур.
- Qt offscreen / software: настоящий рендер в PNG, проверка alpha=0
  вне рамки и внутри неё, alpha=255 на контуре.
- Проверены обратное выделение, отрицательные координаты экранов, отмена,
  минимальный размер, передача результата из Qt и отделение библиотек Qt
  от библиотек замороженного Python-приложения. 13 unittest проходят.
- Проверка на живом рабочем столе всё ещё недоступна из sandbox.
- Для macOS настроен прозрачный фон Tk, для Windows почти прозрачный
  приёмник ввода и отдельные видимые края; эти ветки не проверялись на ОС.

## Исправление 0.1.2: альфа-канал нативного окна

В 0.1.1 проверялось изображение сцены offscreen, а не формат поверхности
графического окна. Такая проверка не доказывала прозрачность в композиторе.
Qt QML runtime теперь запускается с `--transparent` (явный запрос альфа-канала)
до создания окон выделителя.
Удалён вызов `showFullScreen()`, используются обычные безрамочные поверхности.
Документация Qt: https://doc.qt.io/qt-6/qtqml-tooling-qml.html
Реальный рабочий стол по-прежнему недоступен из sandbox; успех на нём не подтверждён.

## 0.2.0: эффекты и магнитная рамка

43 встроенных эффекта (24 новых), 20 unittest. Каждая сцена проверена при
нескольких размерах, включая 1×1, и после изменения размеров.
Проверены привязка углов/сторон, ближайшее из двух окон, отсутствие привязки
к далёким продолжениям сторон, отрицательные координаты и передача --snap
от запуска до GUI. Настоящий Qt/QML движок offscreen подтвердил совпадение
поведения магнитной и свободной рамки.

KDE D-Bus bridge реализован на ctypes/GLib, API сверено с исходником KWin.
Проверка живого bridge заблокирована sandbox; даже приватный тестовый D-Bus
не разрешено создать (bind: Operation not permitted). Windows/macOS источники
геометрии и новые сочетания не проверены на живых ОС.

## 0.3.0: вкладки, системы, управление и автопоказ

- 33 unittest: формулы CPU/RAM/disk/network, сбросы счётчиков, отдельные
  журналы и ротация, read-only сканер/symlink/hardlink, календарь, slideshow.
- 43 анимации + 12 встроенных системных инструментов + 41 внешний проект.
- На текущем Linux получены настоящие CPU/RAM/процессы, disk I/O и ёмкость дисков.
- PTY: вкладки, performance с JSONL, календарь/год, terrain -> N -> dna,
  R на кириллице, автопоказ через A, штатный выход.
- Оконные обработчики исполнены с моделью Tk-виджетов без display: N/R
  на самом Text до class-binding, кириллица, удержание R 2 с, таймер30–120 с.
  Это не тест живого Tk/рабочего стола; исходный баг focus/class-binding
  устранён в коде, но реальное поведение на машине пользователя ещё нужно подтвердить.
- macOS/Windows мониторинг psutil, native GUI и hotkeys не проверены на живых ОС.

## 0.4.0: типографика и настоящий fastfetch с 3D

37 unittest: дополнительно четыре шрифта, адаптация размера/обрезка, разная
геометрия шрифтов, разбор цветного логотипа fastfetch и вращение 3D, фильтрация

скриншот живого терминала. Tk/desktop по-прежнему не проверены.

## 0.5.0

Добавлен автономный каталог 541 логотипа, проверен выбор Windows/macOS/Arch/

Предпросмотры ОС — иллюстрация ресурсов, не факт запуска Windows/macOS.

## 0.6.0
