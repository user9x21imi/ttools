# tspotify · музыка из точек

Терминальный клиент Spotify с цветными точечными обложками, мини-обложками в списках,
плавным спектром реального аудиовыхода и настраиваемой раскладкой окон.

## Установка

**[Скачать последний релиз](https://github.com/user9x21imi/tspotify/releases/latest)** · Linux x86_64 · macOS Apple Silicon · macOS Intel · Windows x64

В каждом нативном архиве уже есть Python, зависимости и движок. Распакуйте архив и запустите `./tspotify/tspotify`; на macOS также можно открыть `Start tspotify.command`. Отдельная программа Spotify не нужна. CI собирает и запускает автономную проверку на каждой системе; работу со звуком на реальном оборудовании каждой ОС сборка не подтверждает.

### Установка исходников

Для исходников нужен **Python 3.11 или новее** с `venv` и `pip`. Git и права администратора не нужны. Локальные команды и Jam требуют исправленного движка tspotify; Linux-архив выше уже содержит его. Установка исходников по умолчанию скачивает исходный upstream-движок.

Linux / macOS — выполните три команды:

```sh
python3 -m venv "$HOME/.local/share/tspotify/venv"
"$HOME/.local/share/tspotify/venv/bin/python" -m pip install "https://github.com/user9x21imi/tspotify/archive/refs/heads/main.zip"
"$HOME/.local/share/tspotify/venv/bin/tspotify"
```

Windows PowerShell — нужен Python 3.11+ с командой `py`:

```powershell
py -3 -m venv "$env:LOCALAPPDATA\tspotify\venv"
& "$env:LOCALAPPDATA\tspotify\venv\Scripts\python.exe" -m pip install "https://github.com/user9x21imi/tspotify/archive/refs/heads/main.zip"
& "$env:LOCALAPPDATA\tspotify\venv\Scripts\tspotify.exe"
```

Для следующего запуска повторите последнюю команду для своей ОС. Анимированное окно в стиле Fastfetch показывает сведения о системе во время загрузки движка и остаётся ещё три секунды после готовности Spotify. `--no-splash` отключает окно, `--no-motion` отключает переходы интерфейса, а `--low-power` уменьшает частоту обновления и пропускает переходы. Добавьте `--demo` для просмотра без аккаунта и звука или `--muted` для запуска с нулевой громкостью. Встроенное воспроизведение требует Spotify Premium. При установке исходников движок с проверкой контрольной суммы загрузится при первом запуске; в нативном архиве он уже есть.

## Вход

При запуске откроется официальный вход Spotify в браузере. Уже открытая браузерная сессия
обычно позволяет просто подтвердить доступ. Пароли клиент не собирает.

`tspotify login --qr` показывает QR-код. После подтверждения на телефоне нужно скопировать
полный адрес возврата в терминал: телефон не может автоматически обратиться к localhost компьютера.
Встроенное воспроизведение может потребовать отдельного подтверждения доступа.

Если настольный Spotify уже запущен и виден как устройство Spotify Connect, он выбирается автоматически.
Чужие приватные токены из официального приложения не извлекаются.

## Разделы и мышь

1 — плейлисты, 2 — любимые, 3 — альбомы, 4 — недавно прослушанное,
5 — ваши сохранённые миксы Spotify, 6 — новые релизы, 7 — рекомендации по вашим часто прослушиваемым трекам,
8 — сохранённые миксы дня. Нужные миксы сначала сохраните в официальном Spotify: закрытая главная страница Spotify не копируется.
Доступность новинок и рекомендаций зависит от разрешений Spotify; недоступный раздел показывает объяснение.

Мышь: наведение выделяет панель, одинарный щелчок открывает плейлист или включает трек,
колесо прокручивает список. Вкладки, обложка, громкость и кнопки управления нажимаются мышью.
Для выделения текста используйте Shift, если это требуется терминалу.

F3 или кнопка «Плеер» открывает крупную точечную обложку, информацию о треке и плавный точечный спектр под ней.
F3/Esc возвращает обычный интерфейс. Для обложек используется исходник 256×256; фактическая детализация зависит от размера терминала.

## Основные клавиши

`/` — поиск · Enter — открыть плейлист/включить трек · `P` — весь плейлист · `f` — избранное
· `+`/`-` — громкость · `m` — без звука · `L` — раскладка · `a` — стиль обложки
· F7 — предыдущий трек · F8 — играть/пауза · F9 — следующий · F10 — mute · F11 — тише · F12 — громче (также в поиске и справке).
· `?`/F1 — все клавиши · **Ctrl+Q** — сохранить сессию и выйти (`q` и Ctrl+C тоже работают).

Шрифты: обычные Cascadia Mono, Menlo, JetBrains Mono или Fira Mono. Если точки не отображаются,
используйте `tspotify --ascii`. На компактном терминале 78×24 панель спектра тоже видна; увеличьте окно, чтобы дать больше места обложке и библиотеке. Прозрачность берётся из настроек терминала.

Спектр на Linux захватывает только конкретный поток встроенного Spotify через `parec --monitor-stream`.
Уведомления, браузер и другие приложения в спектр не попадают. После пересоздания потока или смены выхода захват переподключается.
В macOS/Windows для спектра нужно направить только Spotify в отдельный виртуальный аудиоканал и указать его точное имя/ID
в `TSPOTIFY_SPOTIFY_LOOPBACK`. Доступные входы можно посмотреть командой `python -c "import soundcard as sc; print('\\n'.join(x.name for x in sc.all_microphones(include_loopback=True)))"`.
Используйте маршрутизацию звука по приложениям, чтобы в этот канал попадал только встроенный Spotify. Общий системный выход автоматически не захватывается.
Для внешнего Spotify Connect локальный звук недоступен: вместо него не показывается системный звук компьютера.
Без спектра воспроизведение продолжает работать. Физический микрофон автоматически не выбирается.

Под громкостью есть нажимаемые −/+, «Играть/Пауза», звук, предыдущий/следующий трек и избранное.
Нижняя строка действий, настройка окон и навигация справки тоже управляются мышью. Щелчок по полосе прогресса перематывает трек.

Нужен Spotify Premium для встроенного воспроизведения. Сборки пока без подписи разработчика;
macOS/Windows могут запросить подтверждение запуска.

Сборки и тесты в CI не заменяют проверку воспроизведения на настоящем оборудовании каждой ОС.
[Полная документация](../README.md) · [Решение проблем](TROUBLESHOOTING.md).

### Обновления

Установленная сборка проверяет новые стабильные релизы GitHub раз в сутки перед открытием интерфейса. При наличии обновления показывает версию и спрашивает `Install update? [y/N]`: Yes — установить, No или Enter — продолжить без обновления. Загрузка привязана к выбранному релизу и проверяется по SHA-256. Вход и настройки сохраняются. После установки снова запустите `tspotify`. Без интернета клиент продолжает запускаться.

Для ручной проверки: `tspotify update`.

[Готовый промпт для отдельного SoundCloud-клиента](SOUNDCLOUD_PROMPT.ru.md).

## Память сессии

Клиент запоминает громкость, последний трек и позицию, открытый раздел/плейлист, выделенную строку, поисковый текст и полноэкранный вид. Следующий запуск восстанавливает их **на паузе**: Space продолжает с сохранённого места. Для первого запуска используется 35%. Если вы сами оставили 0%, это значение также сохраняется. Для кнопки `m` отдельно запоминается ненулевая громкость.

Состояние сохраняется периодически и при выходе, в том числе через Ctrl+Q или обычное закрытие окна терминала. `--muted` — временный тихий режим: он не затирает обычную громкость и сессию. Демонстрационный режим тоже отделён. Уже играющее внешнее устройство Spotify Connect использует своё текущее состояние. Файл сессии находится в личной папке конфигурации (`tspotify doctor`).

## F-клавиши при свёрнутом терминале

В KDE Plasma один раз выполните `tspotify install-shortcuts` и перезапустите клиент. F7 — предыдущий трек, F8 — играть/пауза, F9 — следующий, F10 — mute, F11 уменьшает громкость на 5%, F12 увеличивает на 5% — даже при свёрнутом окне и фокусе в другом приложении. Пока клиент запущен, клавиши закреплены за Spotify; при штатном выходе освобождаются. Чужие назначенные сочетания не перезаписываются. Отключение: `tspotify install-shortcuts --remove`.

В других оболочках команды `tspotify control volume-up`, `tspotify control volume-down` и `tspotify control mute` можно назначить через их системные настройки. Автоматическая настройка пока относится к KDE. Эти команды не запускают музыку или новый клиент: они передают изменение громкости уже работающему экземпляру.

Быстрые нажатия больше не отбрасываются: желаемая громкость накапливается, запросы упорядочиваются, старые ответы опроса её не откатывают. Обложка текущего трека загружается отдельно от миниатюр, использует подходящий размер изображения и кеш готовой точечной картинки.

Изменения громкости объединяются после паузы нажатий 180 мс и отправляются не чаще раза в секунду. Повторы на 0% и 100% не создают запросов. При ограничении Spotify 429 сохраняется последнее желаемое значение; клиент сам ждёт Retry-After и применяет его без повторного нажатия. До подтверждения показаны очередь и последнее подтверждённое значение.

### Перемешивание, повтор и ссылки

`s` переключает shuffle; `r` переключает повтор: выключен → список → один трек → выключен. Кнопки доступны мышью внизу клиента и в развёрнутом плеере. Встроенный движок v5 выполняет эти команды локально через Spotify Connect. Если установлен старый движок, клиент явно запросит обновление.

`y` / кнопка **Share** показывает и копирует ссылку на текущий трек; `Y` — на выбранный трек, альбом или плейлист. Для буфера обмена поддерживаются macOS pbcopy, Windows clip.exe, Linux wl-copy/xclip/xsel и KDE Klipper. Если буфер недоступен, ссылка остаётся в окне для ручного копирования.

`j` / **Jam** запрашивает создание или текущую сессию через авторизованный встроенный движок. В окне показаны участники, если Spotify их вернул, и настоящая ссылка приглашения с кнопкой копирования внизу. Публичный Web API для этого не используется; это внутренний механизм Spotify, который сервис может изменить или отклонить. Ошибка сервера показывается явно; ссылка на трек или справку не выдаётся за приглашение. Автоматическая рассылка друзьям не выполняется.

### Полноэкранный плеер и конец очереди

F3 открывает полноэкранный плеер: точечная обложка и сведения о треке образуют главный блок, а спектр занимает отдельную область под реальным таймлайном. В узком терминале обложка и сведения расположены сверху вниз. Фактический следующий трек показан над таймлайном с учётом shuffle и повтора одного трека.

Когда конечная очередь заканчивается, это показано явно. Space запускает закончившуюся очередь с начала; Next после остановки запускает очередь с начала. Во время обычного воспроизведения Next переходит к следующему элементу очереди.

В широком основном окне плеер и спектр располагаются слева, библиотека — справа. При вертикальном окне панели идут сверху вниз. Временная раскладка поиска разворачивает список результатов, не изменяя сохранённый порядок панелей. Примеры обычного и полноэкранного режима, записи переходов и замеры находятся в [документе о новом интерфейсе](EDITORIAL_UI.md).
