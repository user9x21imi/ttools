# tsound

Терминальный клиент SoundCloud в стиле tspotify. Плеер показывает форму волны по всей длительности и отмечает на ней комментарии. Когда плейхед пересекает отметку, под волной на несколько секунд появляется автор и текст. Комментарии появляются поверх волны. Под ней расположены воспроизведение, переключение треков и громкость. Рядом отображается цветная точечная обложка.

## Быстрый просмотр

Python 3.10+ и терминал с поддержкой curses. Деморежим работает без сети, аккаунта и звука.

```sh
tsoundcloud --demo
```

Команда `tsoundcloud` открывает плеер после заставки. Если команда ещё не установлена, из каталога проекта можно запустить `python -m tsound --demo`.

Нажмите пробел. Первый комментарий появится через две секунды. F3 открывает большой плеер. Флаг `--ascii` переключает рамки, форму волны и обложки на ASCII. Флаг `--no-splash` отключает стартовый логотип.

## SoundCloud

Для обычного запуска нужны FFmpeg в `PATH` и SDL2. При необходимости укажите путь к библиотеке SDL2 в `TSOUND_SDL2`. Установка Python-пакета не запускает плеер.

```sh
python -m venv .venv
.venv/bin/python -m pip install .
```

При первом запуске откроется окно SoundCloud. Его также можно вызвать по F5. Enter использует сессию SoundCloud из обычного профиля Zen Browser или Firefox, если он выбран браузером по умолчанию. После первого успешного входа клиент запоминает выбранный профиль и восстанавливает действующую сессию при следующих запусках. В файле настройки хранится только путь к профилю; сессия остаётся в браузере. Если сессии ещё нет, клиент открывает страницу входа и ждёт её появления. При сбое открытия страницы можно вручную открыть `https://soundcloud.com/signin` в том же браузере, пока терминал ждёт.

Клавиша **S** открывает вход в отдельном профиле Zen Browser или Firefox. Поддерживаются Flatpak-версии обоих браузеров. [Пример такого подхода в Kopuz](https://github.com/Kopuz-org/kopuz#soundcloud-setup)

Для альтернативного официального OAuth разработчик настраивает данные зарегистрированного приложения через `SOUNDCLOUD_CLIENT_ID`, `SOUNDCLOUD_CLIENT_SECRET` и `SOUNDCLOUD_REDIRECT_URI` или приватный `credentials.json` (ключи `client_id`, `client_secret`, `redirect_uri`). Текущая реализация принимает зарегистрированный локальный адрес вида `http://127.0.0.1:ПОРТ/callback`; регистрацию приложения с этим адресом нужно подтвердить в SoundCloud. Для публичной поставки общий секрет должен оставаться на стороне сервера.

Токен и сессия хранятся в каталоге настроек пользователя. На Linux используется `$XDG_CONFIG_HOME/tsound` или `~/.config/tsound`. Для изолированного запуска доступна переменная `TSOUND_HOME`.

Станции в разделе «Миксы» берутся из лайков пользователя. Раздел «Приложения» содержит сведения о клиенте. При отсутствии готовой формы волны клиент пытается построить её в фоне из доступного полного потока, сохраняя в памяти только пики. У фрагментов и треков с ограничением доступа форма волны может отсутствовать.

[Руководство SoundCloud API](https://developers.soundcloud.com/docs/api/guide) · [Спецификация SoundCloud API](https://developers.soundcloud.com/docs/api/explorer/)

## Управление

- F2 ищет по всему SoundCloud. `/` фильтрует открытую коллекцию, плейлисты или любимые треки.
- Стрелки, колесо и мышь управляют списком. Enter открывает коллекцию или воспроизводит трек.
- Наведите мышь на точку формы волны, чтобы прочитать комментарий. Перетащите плейхед для перемотки.
- F3 разворачивает плеер. F4 или B отдаёт экран библиотеке и оставляет внизу мини-обложку и спектр. Повторное F4 или Esc возвращает обычную раскладку.
- F7–F12 управляют очередью, паузой и громкостью. S перемешивает очередь, R переключает повтор очереди или трека, Y показывает ссылку или копирует её, если доступна утилита буфера обмена. В F3 под волной видно, какой трек следующий. `L` меняет раскладку. F1 показывает команды. Ctrl+Q завершает работу.

## Проверки

```sh
python -m unittest discover -s tests -v
```

Проверки используют локальный псевдотерминал и SDL с беззвучным выводом. Для живого прогона OAuth, потоков и библиотеки нужен доступ к SoundCloud. Системные медиаклавиши, macOS, Windows и интеграция обновлений с ttools пока не проверены.
