# SoundCloud → ttools

Компонент `tsoundcloud` 0.1.0. Добавь как самостоятельное терминальное приложение **SoundCloud**. В `app.json` указаны точные массивы аргументов. `${BUNDLE}` — абсолютный путь к этой папке. Передавай аргументы напрямую и выделяй приложению собственный PTY. Для зависимостей нужен Python 3.10+ с curses, для звука — FFmpeg, SDL2 и рабочий аудиовыход.

## Запуск

- Обычный запуск — `python3 "${BUNDLE}/launch.py"`.
- Беззвучный офлайн-прогон — `python3 "${BUNDLE}/launch.py" --demo --no-splash`.
- Версия — `python3 "${BUNDLE}/launch.py" --version`.
- Штатное завершение — Ctrl+Q, байт `0x11` во вход PTY этого экземпляра. Дождись выхода. У приложения пока нет внешней команды stop.
- Установочного шага нет. `launch.py` проверяет SHA-256 и запускает приложенный wheel напрямую. Публичного канала обновлений пока нет. Настройки пользователя расположены вне поставки.

## Что показать агенту и проверить

В плеере есть форма волны на всю длительность, точки комментариев с предпросмотром при наведении, перемотка перетаскиванием и точечные обложки. F3 открывает большой плеер, F4 или B — расширенную библиотеку с мини-плеером. F2 запускает общий поиск, / фильтрует открытую коллекцию. F5 открывает окно входа.

Демо работает на Linux/SteamOS. В исходном проекте прошли десять автоматических тестов, включая PTY, перемотку, комментарии, F4 и беззвучный вывод SDL.

**Живой вход требует проверки.** Предыдущая сборка показывала ошибку открытия Zen через Flatpak. Текущая сборка по Enter сначала проверяет существующую сессию SoundCloud в основном профиле браузера, выбранного по умолчанию. Если входа ещё нет, она пытается открыть сайт через Zen Flatpak, KDE или системный обработчик и ждёт входа. Если окно не открылось, можно открыть https://soundcloud.com/signin вручную в том же профиле, пока терминал ждёт. Профиль Zen на целевой машине найден без чтения cookies. Возврат в терминал проверен на тестовых данных. Реальный аккаунт, библиотека и потоки по сети пока не подтверждены. Отдельный профиль остаётся доступен по S.

В поставке только исходники, wheel и инструкции. Пользовательские профили браузера, сессии и секреты не входят в пакет. Windows и macOS в этой поставке не проверялись.

Обновление: после успешного входа клиент запоминает путь к выбранному профилю браузера в локальном файле web-login.json. При следующем запуске действующая сессия подключается автоматически. Содержимое сессии остаётся в браузере. Непройденная часть формы волны рисуется тонкими полосками, пройденная — мелкими оранжевыми точками. 13 тестов прошли, включая восстановление входа на тестовых данных.
