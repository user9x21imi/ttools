# Проверки кандидата ASCII-редизайна

Среда: Linux x86_64 / SteamOS, CPython 3.14. Проверки не используют личные аккаунты, микрофон или подключение VPN.

- 25 тестов лаунчера и дистрибутива проходят: защита ZIP, SHA и полный инвентарь, обновление/откат, пути с Unicode, объединение каталогов, PTY-навигация, resize, запуск дочернего процесса и возврат.
- Проверены два слоя фона, пауза и продолжение, смена в паузе, resize при переходе, кэширование кадров, ограничение low-power и отсутствие повторной записи неизменённых ячеек.
- 65 тестов bundled tthings 0.7.2 проходят.
- Все 200 эффектов отрисованы на трёх временных отметках; [отчёт](effects-audit.json). 19 инструментов подсчитаны отдельно, внешних ссылок 41. Запуск системных инструментов с доступом к устройствам этим аудитом не проверяется.
- 8 тестов полного Windows-пакета ttelegram проходят на Linux. Это симуляция транзакций и общая VT-логика, не Windows-сертификация.
- Локально собраны все четыре ZIP: Linux и Windows с четырьмя приложениями, macOS ARM/Intel без Telegram. Полные файловые манифесты проверены verify_bundle. Windows DLL локально не исполнялись.
- Созданы шесть настоящих workspace-кадров 1920×1080 и GIF 960×540. Каждый кадр записан в собственном Xvfb / DBus, с временными XDG-каталогами и вымышленными данными.

## Производительность

[Измерения двухслойного фона](background-benchmark.json): 120×40, 20 кадров на пару, process_time, без терминала и композитора. При 10 кадрах/с это оценка одного ядра, а не общего CPU системы. В отчёте также 1000 вызовов закэшированного неподвижного кадра. Производительность зависит от сцены и размера; для батареи предусмотрены low-power и полная пауза.

[Замер живого PTY-цикла](idle-cpu.json): после секунды прогрева три секунды при 120×40 дали 10.9% одного ядра в обычном режиме, 7.6% в low-power и 2.3% без движения. Это по одному короткому замеру с разными случайными вторыми сценами, не строгий сравнительный бенчмарк и не гарантия для других устройств.

README проверен непосредственно на GitHub: 390 px в светлой теме и 1280 px в тёмной, без горизонтального переполнения markdown-блока. Локальные ссылки целы, новые изображения открываются.

## CI и Windows

Предыдущий успешный опубликованный общий релиз: [1.1.0-preview.1](https://github.com/user9x21imi/ttools/releases/tag/v1.1.0-preview.1), [CI](https://github.com/user9x21imi/ttools/actions/runs/44331944599).

Windows-кандидат в main не прошёл [run 44384142702](https://github.com/user9x21imi/ttools/actions/runs/44384142702): прямой импорт `_curses` в upstream views и сравнение короткого/полного имени пути в тесте. В этой ветке исправлены VT alias и сравнение resolve(). macOS Intel PTY-тест ожидал готовность фиксированные 0.5 секунды; теперь он ждёт фактического появления интерфейса. Тесты не удалены.

В [PR run 44391792627](https://github.com/user9x21imi/ttools/actions/runs/44391792627) прошли тесты Linux, macOS ARM/Intel и Windows. Windows CI выполнил настоящую offline-установку, doctor, импорт native TDLib 1.8.66 и FFmpeg без аккаунта. Это проверка runtime на Windows Server 2022, не ручной тест Windows Terminal.

Не проверены: живой Telegram-вход и 2FA на Windows, визуальная работа SIXEL в Windows Terminal, clipboard, микрофон и воспроизведение на Windows, реальные Spotify/VPN-сессии на всех ОС. Компонент Windows остаётся предварительным даже после успешного doctor.
