# Проверки релизного кандидата

Локальная среда: Linux x86_64 / SteamOS, CPython 3.14, glibc 2.43.

- 19 тестов общего клиента и дистрибутива: манифесты, argv с Unicode,
  переимпорт, поиск/resize/возврат в PTY, выделение, защита распаковки от
  traversal/symlink, SHA-256, полный список файлов, блокировки,
  сохранение активной версии при ошибке, повторная установка и откат без VPN,
  применение проверенного обновления через новый installer и ожидание дочернего cleanup.
- Для Windows/macOS тестируется явный отказ полной установки, поскольку
  Telegram передан только для Linux. Неполный режим требует явного выбора.
- Проверки авторов приложений описаны в components/*/HANDOFF.md. Они относятся
  к переданным компонентам и не заменяют интеграционный прогон всего ttools.

Интеграционная установка всех четырёх приложений в `/tmp/ttools проверка/установка`
успешна, включая native Spotify, offline-wheelhouse Telegram, исходники tthings
и TVPN install-only. Проверены Spotify --version, Telegram --help и tthings
--version. Установка выполнена с --defer-system --no-shortcuts: системный
VPN-backend, sudoers, авторизация и пользовательские ярлыки не менялись;
в состоянии правильно отмечено complete=false. Это проверка установки
пользовательских файлов, не доказательство готовности VPN-туннеля.

У установленного комплекта проверен PTY-сценарий: библиотека → tthings →
возврат → выход. Временные XDG-каталоги изолировали настройки; записи активных
экземпляров после выхода удалились. Повторная установка не меняет файлы.

Созданы и проверены файловые манифесты четырёх платформенных ZIP-архивов.
Полный поддержанный состав указан только у Linux; остальные помечены неполными.
 CI настроен для Linux/macOS/Windows; пока workflow не
запущен на GitHub, успешное прохождение CI не заявляется.

Не выполняются автоматически: вход в аккаунты, чтение переписки, воспроизведение
музыки, запись микрофона, VPN-туннель и изменение системного звука.
