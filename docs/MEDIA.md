## Изоляция

Не используются личные аккаунты, QR, переписка, файлы авторизации или записанный микрофон. Spotify работает в demo. Telegram fixture блокирует чтение реального tg/conf.py, использует временные каталоги и fake backend без TDLib-клиента; Path.home внутри процесса тоже изолирован. TVPN демонстрирует карту без вызова backend. Сцены tthings получают только размер, seed и время.

GIF не подтверждают сетевые функции, воспроизведение реальной музыки и аппаратный ввод. Метаданные изображений не содержат EXIF и путей пользователя.

## Воспроизведение графики

На Linux нужны Pillow и DejaVu Sans / Mono:

```sh
python -m pip install -e '.[docs]'
python tools/render_editorial.py
python tools/render_variants.py
python tools/audit_effects.py
python tools/render_docs.py
```

`render_variants.py` использует seed 181126: случайные пары воспроизводимы. Номера и палитры — в studies/manifest.json. Это подборка для выбора автором; не все варианты автоматически становятся темами клиента.

Старые записи приложений можно повторить через `tools/render_showcase.py --suite-prefix <изолированная-установка>`. Они остаются рендерами терминального вывода.

## Настоящие рабочие столы

Съёмка выполняется только в отдельном виртуальном X-сервере, собственной DBus-сессии и временных XDG-каталогах. Хостовый рабочий стол не снимается и его разрешение не меняется. Не запускать rootful Xwayland: он открывает видимое окно. Для невидимой среды нужен Xvfb и отдельный kwin_x11.

Перед публикацией проверяются каждый кадр, заголовки, панель, мелкий текст и метаданные. Пустые или неправильно собранные кадры не заменяются нарисованными окнами. Все workspace-кадры — 1920×1080 без растягивания; GIF уменьшается целиком до 960×540.

Для съёмки используется уже установленный изолированный Linux-suite. Нужны Xvfb, kwin_x11, Konsole, xdotool, Pillow, python-xlib и Tk для нейтрального фона виртуального стола. Запуск:

```sh
dbus-run-session -- python tools/capture_workspaces.py --suite-prefix /path/to/demo-suite
```

`--xvfb /path/to/Xvfb` позволяет использовать отдельно распакованный бинарник без системной установки. Скрипт никогда не переключается на видимый Xwayland; при отсутствии Xvfb завершится с ошибкой. Графический wallpaper используется только внутри среды съёмки; продукт остаётся терминальным клиентом. Все собственные процессы закрываются после записи.

`tools/benchmark_backgrounds.py` измеряет CPU двух рендереров без UI; `tools/benchmark_idle.py` — живой Linux PTY-цикл с фиктивным каталогом в состояниях паузы, движения и `--no-motion`. Результаты не описывают весь компьютер и не экстраполируются на остальные платформы.

`launcher-before/after.gif` записаны из настоящего TTY через `tools/media_terminal.py`; в каталог переданы пять синтетических приложений с `/usr/bin/true`, аккаунты и сеть не используются. Старая версия для кадра до редизайна взята из `HEAD`, новая — из рабочей копии. Клавиши `j` переключают выбор. `launcher-80x24.png` и `launcher-160x50.png` сняты тем же PTY-захватом; промежуточный `interface.png` остаётся отдельным программным рендером ячеек.

`--startup-preview` у capture_workspaces.py снимает новую заставку настоящего терминального клиента. Только для захвата длительность показа увеличена до четырёх секунд; в обычном клиенте — 1.35 секунды, с пропуском по клавише. Результат — startup-desktop.png. Фон берётся из текущего профиля терминала, не из заставки-картинки.

## Редакционная доработка PR №1

Новые `app-spotify.png`, `app-spotify-player.png`, `app-telegram.png`, `app-vpn.png` и `app-tthings.png` — настоящие кадры больших окон Konsole. Для отдельных интерфейсов выбран более крупный шрифт; снимки не растягивались и не собирались из отдельных панелей. В Telegram добавлены четыре вымышленных сообщения и черновик, изображение — локальная ASCII-композиция проекта. Никакой Telegram-клиент TDLib или настоящий аккаунт не создаётся.

`tools/editorial_assets.py` развивает пять существующих миксов 00/02/03/04/07. Создаются тёмный hero, четыре невысоких разделителя, новая статическая галерея и фоновые композиции для шести раскладок. Разделители и галерея — художественные рендеры, не снимки интерфейсов. Вся важная информация остаётся обычным Markdown-текстом.

`capture_workspaces.py` устанавливает сгенерированный фон **внутри** Xvfb до съёмки. Рисунок исключается из областей окон и отдельно размещается в свободных верхних/нижних полях. Для Music & Focus, Daily Setup, галереи и экспериментальной раскладки используются свои палитры. Обновление фона атомарное; готовый кадр рабочего стола после захвата не композится.

Схема Breeze Dark берётся из системного `/usr/share/color-schemes/BreezeDark.colors` только для временного XDG-каталога. Личные настройки рабочего стола не читаются и не копируются. Светлая бумажная подложка текущих workspace-снимков удалена. Старые исследования в studies сохранены как архив.

Чтобы повторить текущую презентацию:

```sh
python tools/editorial_assets.py
dbus-run-session -- python tools/capture_workspaces.py --suite-prefix /path/to/demo-suite
dbus-run-session -- python tools/capture_workspaces.py --suite-prefix /path/to/demo-suite --startup-preview
```

Предыдущий `render_editorial.py` сохраняет исходную светлую концепцию. Для актуальной тёмной страницы после него выполняется `editorial_assets.py`; новые серии studies не требуются.
