# Как сделаны изображения и GIF

Материалы собираются из интерфейсов и рендереров проекта. В коллаже нет
приватных чатов, аккаунтов, IP, авторизационных QR или записанного микрофона.

| Файл | Источник |
|---|---|
| showcase.png | Коллаж четырёх демонстрационных интерфейсов с общим оформлением |
| spotify.gif | Настоящий `tspotify --demo --no-splash`, PTY, без аккаунта/аудио |
| telegram.gif | Настоящий интерфейс ttelegram, изолированный fake-backend, вымышленные чаты и синтетическое фото |
| vpn.gif | Настоящие Model/draw/globe TVPN, демонстрационное состояние без подключения и реального IP |
| tthings.gif | Четыре настоящих рендерера API tthings, кадры последовательно по времени |
| effects-wall.png | Девять настоящих сцен tthings: ленты, сияние, галактика, Matrix и другие |
| demo.gif | Настоящая UI.draw ttools с приглушённым процедурным фоном и цветами выбора |

GIF демонстрируют соответствующие режимы, а не устанавливают факт проверки
реального воспроизведения, сети или аккаунтов. Спектр в Spotify demo —
демонстрационный; реальный режим приложения получает данные аудио отдельно.
PNG/GIF показывают непрозрачную подложку, не системный compositor blur.

## Повторить на Linux

Нужны Pillow, DejaVu Sans/Mono и установленный изолированный Linux-suite,
в котором есть Spotify native runtime и Telegram venv с авторским патчем tg.

```sh
python3 -m pip install -e '.[docs]'
python3 tools/render_docs.py
python3 tools/render_showcase.py --suite-prefix '/путь/к/тестовой/установке'
```

`media_telegram_fixture.py` — отдельный демонстрационный backend. Перед импортом
клиента он блокирует чтение реального `~/.config/tg/conf.py`, подставляет
временные каталоги, фиктивные сообщения и локальные изображения. Все операции
запросов/отправки обслуживаются им в памяти, TDLib-клиент не создаётся.
Не используйте fixture как настоящий Telegram-клиент.

`media_terminal.py` читает вывод PTY и рисует его клетки с цветами и Braille.
Это воспроизводимый рендер терминального вывода, а не фотография рабочего
стола. Параметры и длина GIF записаны в docs/assets/media.json.
