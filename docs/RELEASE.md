# ttools 1.1.0 preview

Общий установщик, платформенные архивы, проверка SHA-256, согласованные
снимки приложений и механизм обновления всего комплекта при следующем запуске.

- Linux x86_64: ttools + tspotify 0.1.0 + ttelegram 2026.11.18.4 + TVPN 1.3.1 + tthings 0.7.0.
- macOS ARM64/x86_64 и Windows x86_64: preview для ttools + Spotify + TVPN + tthings; Telegram пока недоступен. Нужен явный --allow-partial / -AllowPartial.
- Установка не запускает OAuth, музыку, Telegram-вход или VPN-подключение.
- Сохраняются пользовательские настройки и авторизация.
- Новая версия проверяется по SHA-256 и полному файловому манифесту.
- Обновление работающего комплекта блокируется; новая версия сначала готовится отдельно.
- Цвета выбора: Spotify зелёный, Telegram синий, VPN фиолетовый, tthings фуксия; SoundCloud/YouTube зарезервированы на будущее.

Нативные сценарии с аккаунтами/реальной музыкой и VPN-туннели на всех ОС этим
preview не объявляются проверенными. Полный native Telegram для Windows/macOS
требует отдельного пакета от автора. Подробности в README и docs/VALIDATION.md.
