# ttools 1.1.0-preview.4 — предварительный комплект

tspotify обновлён до 0.2.0. Во время запуска показывается Fastfetch-экран с информацией о системе; он остаётся ещё три секунды после готовности Spotify. Спектр теперь виден в компактных терминалах 78×24, включая стандартный размер окна Terminal.app.

Самостоятельная сборка tspotify создаёт архивы для Linux x86_64, macOS ARM/Intel и Windows x64. В комплекте ttools приложение устанавливается из исходников на каждой поддерживаемой платформе. Работа аудиозахвата macOS/Windows на реальном оборудовании не проверялась.

SoundCloud 0.1.0 остаётся доступен только в Linux-комплекте.

Linux-комплект теперь включает SoundCloud 0.1.0: самостоятельный терминальный плеер с формой волны и отметками комментариев. Его исходник и проверенный wheel входят в архив; живой вход и потоки ещё требуют проверки на целевой машине. SoundCloud пока доступен только на Linux x86_64.

macOS предлагает обновить комплект при запуске и сразу перезапускает лаунчер после согласия. Это доставляет текущий интерфейс, анимации и исправления из общего обновления.

Требуются Windows 10/11 x64 и Windows Terminal 1.22+ с SIXEL. Ручная проверка интерфейса, микрофона, clipboard и входа на Windows ещё не выполнена; компонент предварительный. Автоматический doctor проверяется в Windows CI без аккаунта.

macOS ARM/Intel по-прежнему устанавливает комплект без Telegram и SoundCloud через --allow-partial. Установка не открывает аккаунты и не подключает VPN. Настройки и сессии хранятся отдельно от версий программ.

ASCII-редизайн: новый русский и английский README, оригинальная типографика, 24 микса сцен, 6 анимаций и 6 настоящих рабочих столов 16:9. Фон лаунчера смешивает два эффекта, поддерживает паузу и low-power и обновляет только изменённые ячейки. tthings обновлён до 0.7.2: 200 эффектов и 19 инструментов.

После слияния версии в main GitHub Actions создаёт preview Release автоматически, если такого тега ещё нет и проверки всех платформ и сборка архивов прошли. Архивы Releases доступны публично.
