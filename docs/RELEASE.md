# ttools 1.1.0-preview.2 — предварительный комплект

Windows-комплект теперь включает нативный ttelegram 2026.11.18.7-win1: без WSL и tmux, с собственным Python и офлайн-зависимостями. Все четыре приложения устанавливаются общей командой, обновления доставляет ttools. Linux-версия Telegram сохранена.

Требуются Windows 10/11 x64 и Windows Terminal 1.22+ с SIXEL. Ручная проверка интерфейса, микрофона, clipboard и входа на Windows ещё не выполнена; компонент предварительный. Автоматический doctor проверяется в Windows CI без аккаунта.

macOS ARM/Intel по-прежнему устанавливает комплект без Telegram через --allow-partial. Установка не открывает аккаунты и не подключает VPN. Настройки и сессии хранятся отдельно от версий программ.

ASCII-редизайн: новый русский и английский README, оригинальная типографика, 24 микса сцен, 6 анимаций и 6 настоящих рабочих столов 16:9. Фон лаунчера смешивает два эффекта, поддерживает паузу и low-power и обновляет только изменённые ячейки. tthings обновлён до 0.7.2: 200 эффектов и 19 инструментов.

После слияния версии в main GitHub Actions создаёт preview Release автоматически, если такого тега ещё нет и проверки всех платформ и сборка архивов прошли. Архивы Releases доступны публично.
