# Что требуется для полного комплекта на Windows/macOS

Переданный ttelegram 2026.11.18.4 поддерживает только Linux x86_64 / CPython3.14.
Он использует tmux, kdialog, системный GTK/PyGObject, PulseAudio и Linux-wheels TDLib.
Простое переименование архива не делает его приложением для другой ОС.

Автору ttelegram нужно передать:

1. macOS ARM64/Intel: install-only, совместимые wheels/TDLib, native выбор файлов,
   буфер и запись аудио, проверенный жизненный цикл tmux.
2. Windows x86_64: native host вместо Unix tmux/сигналов либо явно поддержанный
   WSL-дистрибутив с полной автоматической подготовкой. Windows-обёртка должна
   запускать именно этот поддержанный вариант; WSL нельзя выдавать за native.
3. Проверенные install/update/rollback, version и stop argv; отдельные артефакты
   с SHA-256, без пользовательской авторизации и переписки.
4. Проверки без аккаунта на настоящих GitHub runners/ОС, включая буфер,
   выбор файлов, fake-runtime, штатный выход и повторную установку.

После передачи этих пакетов общий агент заменит ограничение в suite.plan и
добавит платформенные адаптеры. Сейчас default full install прекращается
до установки; --allow-partial разрешает только явно неполный комплект.
